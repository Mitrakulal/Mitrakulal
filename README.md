## ~/featured

- **[Mattr Chat](https://google.mattrlabs.online)** — ChatGPT-style chat platform backend for a real client, powered by a self-hosted local LLM server (Mac mini M4, Gemma 4).
- **[mattr_labs_RAG](https://github.com/Mitrakulal/mattr_labs_RAG)** — RAG API over Mattr Labs docs: FastAPI + ChromaDB + Ollama.
- **[FPV](https://github.com/Mitrakulal/FPV)** — Zero-cost offline FPV simulator — your Android phone becomes a real transmitter over USB.
- **SmartEval** — AI-assisted evaluation of handwritten answer scripts: handwriting recognition + semantic similarity, lecturer in the loop.
- **[Agent-skills](https://github.com/Mitrakulal/Agent-skills)** — Agent-installable skills, starting with presentation-maker: interactive click-to-reveal slide decks.
